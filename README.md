Sistema de Mantenedor de Datos - ATY1102
Este es un proyecto web estático desarrollado para la gestión de registros de usuarios (Nombre, Email y Ciudad). El sistema incluye un módulo de autenticación básico y funcionalidades completas de CRUD (Crear, Leer, Actualizar y Eliminar) utilizando el almacenamiento local del navegador.

🚀 Características
Autenticación de Usuario: Pantalla de inicio de sesión con validación de credenciales.

Gestión de Datos (CRUD): Permite agregar, listar, editar y eliminar registros de manera dinámica.

Persistencia Local: Los datos se almacenan en el localStorage, por lo que la información se mantiene al recargar la página.

Diseño Responsivo: Interfaz construida con Bootstrap 5.3 para asegurar una buena visualización en diferentes dispositivos.

Configuración de Rastreo: Incluye un archivo robots.txt para gestionar el acceso de motores de búsqueda.

🛠️ Tecnologías Utilizadas
HTML5: Estructura de las páginas.

CSS3: Estilos personalizados (mediante styles.css).

JavaScript (ES6+): Lógica del mantenedor y manipulación del DOM.

Bootstrap 5.3: Framework para el diseño y componentes de UI.

📁 Estructura del Proyecto
index.html: Página de inicio de sesión.

mantenedor.html: Interfaz principal para la gestión de datos.

script.js: Lógica funcional del sistema y manejo de datos.

styles.css: Estilos visuales complementarios.

robots.txt: Reglas de rastreo para bots.

data.json: Archivo base para almacenamiento de datos (actualmente vacío).
